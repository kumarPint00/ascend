# ASCEND // NOCTURNE — v0.11.0 cinematic and native AI release candidate

## What changes in the app

- **Completely redesigned Home**: an original procedural 3D ascension crystal
  rotating in a real OpenGL ES/WebGL scene, three luminous orbital rings,
  depth-distributed stars, floating rank/level overlay and interactive hunter
  profile entry. Requires no textures, remote image service or paid assets.
- **Live atmospheric scene** throughout the application: animated nebula and
  star field with a low-power reduced-motion path. Background does not collect
  data or connect to a server.
- **New Nocturne visual system**: deeper gradients, updated colors, translucent
  panels, luminous meters, revised bottom navigation, more distinctive action
  buttons and native tab reveal transitions.
- **Cinematic rewards**: radial particle ceremony for rank and level-up,
  smaller native-driver completion animation for ordinary quests, with
  OS reduced-motion compliance and touch-transparent overlays.
- **The Oracle**: user-invoked Gemini Nano quest architect with its own
  immersive screen, opt-in prompt, optional sharing of up to five local quest
  titles, model status, explicitly approved model download, input limits,
  structured output validation and fully offline fallback.

## Model integration

`apps/mobile/modules/ascend-nano` is a **real native Expo Android module**.
It uses the official ML Kit Prompt API
`com.google.mlkit:genai-prompt:1.0.0-beta4`, backed by Google AICore/Gemini
Nano. Availability is checked at runtime. On-device generation requires:

1. Android API level 26+ and an AICore-supported device/model version;
2. installed and ready model data, which may need a user-approved download;
3. the app in the foreground;
4. explicit user consent for the generation request.

The Galaxy S25 Ultra is in Google's documented support list, but this does NOT
guarantee the model is present or ready on the owner's device. When status is
unavailable, ASCEND creates a transparent, non-AI **offline starter draft**.
It never claims the fallback text was generated by Gemini.

### Trust boundaries

- The prompt is at most 2800 characters and the model response at most 3500.
- Only one proposal is processed at a time. The parser accepts a constrained
  JSON proposal; fields and character limits are validated before creation.
- Users can edit the title, success criteria, time estimate and goal target.
- Approved model drafts use the existing `decideAdaptiveProposal` SQLite
  transaction: quotas, duplicate checks, low-energy guardrails and Backlog
  insertion apply to Gemini Nano and deterministic proposals alike.
- No automatic XP, automatic activated quest, cloud inference, analytics
  upload, paid AI API or background generation is introduced.
- Existing SQLite v5, adaptive feedback, backup v4 and signed in-place
  upgrades are preserved.

## 3D and rendering guardrails

- `apps/mobile/src/experience/WorldScene.tsx` renders a shaded sphere,
  three dimensional orbital paths and a star field with WebGL and Expo GL.
  This is actual GPU-based 3D geometry, not a static 3D-looking image.
- The renderer runs only while its screen is visible and targets a maximum
  of 30 frames per second; it stops on unmount and uses a single still frame
  for reduced motion.
- Shader failure falls back to a dark gradient rather than crashing the app.
- The real-time scene is an abstract evolving emblem; **not yet a customizable
  full 3D humanoid avatar**. That would require a separate original rigging,
  animation and asset pipeline.

## Release gates

- npm lockfile and `npm ci` must match Expo SDK 58.
- Source CI: game engine rules, package validation, TypeScript.
- Signed Android CI: native Gemini Nano compile, gl dependency/prebuild,
  R8 startup-safe configuration, package `com.ascendrpg.personal`,
  app version 0.11.0, Android versionCode 14, permanent signing cert.
- Emulator: install the actual signed APK, cold launch 3× and confirm
  no process crash. Emulator normally does not expose AICore model inference.
- **Physical Samsung S25 Ultra**: Gemini availability/download/generation,
  real GPU visual quality/performance, Android permission flow,
  accessibility and v5 in-place upgrade with preserved local data.
- Until physical QA passes, ship as a GitHub Actions candidate only; do
  not replace the stable public update feed.
